# chart-monitor

หน้าดูกราฟหลายช่อง (XAUUSD, NASDAQ) ราคาจริงจาก MetaTrader 5 ในเครื่อง วาดด้วย
[Lightweight Charts](https://github.com/tradingview/lightweight-charts) ของ TradingView

```
MT5 (ล็อกอินบัญชีโบรกไว้) → bridge/bridge.py → http://localhost:8000 (หน้ากราฟ)
```

## เริ่มใช้งาน

1. ติดตั้ง [Python](https://www.python.org/downloads/) 3.10 ขึ้นไป (ตอนติดตั้งติ๊ก “Add python.exe to PATH”)
2. เปิด MetaTrader 5 แล้วล็อกอินบัญชี (บัญชี Demo ก็ได้)
3. ดับเบิลคลิก `start-bridge.bat` ครั้งแรกจะติดตั้งไลบรารี MetaTrader5 ให้เอง แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:8000

ต้องเปิด MT5 และหน้าต่าง bridge ทิ้งไว้ตลอดที่ดูกราฟ ข้อมูลไม่ออกนอกเครื่อง
(bridge รับการเชื่อมต่อจาก 127.0.0.1 เท่านั้น)

### ชื่อสัญลักษณ์ของโบรก

bridge หาชื่อให้อัตโนมัติ เช่น `XAUUSD`, `XAUUSDm`, `GOLD` / `NAS100`, `USTEC`, `US100`
ถ้าหาไม่เจอ หน้าต่าง bridge จะบอก ให้กำหนดเอง:

```
start-bridge.bat --symbol XAUUSD=XAUUSD.pro --symbol NASDAQ=US100.cash
```

ตัวเลือกอื่น: `--port 8000`, `--terminal "C:\...\terminal64.exe"` (ถ้ามี MT5 หลายตัว),
`--utc-offset 2` (ถ้าเวลาบนกราฟเพี้ยน ให้ใส่เวลา server ของโบรกเทียบ UTC)

## ฟีเจอร์

- ราคาสดจาก MT5 (ราคา Bid เหมือนกราฟใน MT5) แท่งล่าสุดขยับตามทุก tick
- หลาย layout แต่ละช่องเลือก timeframe ได้ (10s, 15s, 30s, 1m – 1D)
  แท่งวินาทีสร้างจาก tick ของ MT5 ใน bridge (MT5 ไม่มีแท่งต่ำกว่า 1 นาที)
- Crosshair ซิงก์ทุกช่อง ถึงจะต่าง timeframe ก็ชี้แท่งที่ตรงกันให้
- เลื่อนกราฟไปทางซ้ายแล้วโหลดข้อมูลย้อนหลังเพิ่มให้อัตโนมัติ
- แท่งเทียน / Heikin Ashi, Volume (tick volume)
- **Indicators** (ปุ่ม ƒx): SMA, EMA, Bollinger Bands, VWAP, RSI, Stochastic, MACD, ATR
  เพิ่มได้หลายตัว ปรับค่าและสีได้
- **เครื่องมือวาด**: เส้นเทรนด์, Ray, เส้นแนวนอน, เส้นแนวตั้ง, กล่อง, Fibonacci
  บันทึกแยกตามสัญลักษณ์และแสดงตรงกันทุก timeframe คลิกเลือกแล้วลากย้าย / เปลี่ยนสี / ลบ (Delete) ได้ Esc = ยกเลิก
- **Alert**: เลือกเส้นแนวนอนแล้วกด “🔔 ตั้ง alert” เตือนด้วยเสียง + การแจ้งเตือนของเบราว์เซอร์
  เมื่อราคาแตะเส้น (ต้องเปิดหน้าไว้) ดูรายการทั้งหมดที่ปุ่ม 🔔
- เส้น Ask, spread และเวลานับถอยหลังปิดแท่งบนหัวกราฟแต่ละช่อง
- **ทุกสัญลักษณ์ใน MT5**: กด 🔍 หรือพิมพ์ตัวอักษรบนกราฟเพื่อค้นหา คลิกชื่อบนหัวกราฟเพื่อเปลี่ยนเฉพาะช่องนั้น
  🔗 = ทุกช่องเปลี่ยนตามกัน, กดอีกครั้งเพื่อให้แต่ละช่องดูคนละตัว
- **Watchlist** ด้านขวา (☰ / Alt+W): ราคา, % เปลี่ยนวันนี้, spread คลิกเพื่อเปิดกราฟ
- ประเภทกราฟ: แท่งเทียน, แท่งเทียนกลวง, Bar, Heikin Ashi, Line, Area และสเกล Log / %
- **บันทึก layout** (💾) เปิดชุดกราฟที่ตั้งไว้กลับมาได้ทันที
- ขยายช่องเต็มจอ (⤢ / ดับเบิลคลิกหัวกราฟ / Alt+Enter), บันทึกรูปกราฟ (📷 / Alt+S)
- **Sessions**: แถบสีช่วงตลาด Tokyo / London / New York (ปรับเวลา daylight saving ให้เอง) บนกราฟไม่เกิน 1h
- **H/L**: High/Low วันนี้ (ขยับตามราคาสด) และของเมื่อวาน (PDH/PDL) จากแท่ง D1 ของโบรก
- **VP (Volume Profile)** ของช่วงที่มองเห็น พร้อม POC และ Value Area 70%
  นับจาก tick จริงของ MT5 เมื่อช่วงไม่เกิน 1 วัน ถ้ายาวกว่านั้นคำนวณจากแท่ง
- **⏪ Replay**: คลิกแท่งเริ่มต้น แล้วเล่นทีละแท่ง (▶ / ⏭ / Shift+→, 1–10 แท่งต่อวินาที)
  ระหว่าง replay ซ่อนเส้น H/L และ Ask ไม่ให้เห็นราคาอนาคต
- คีย์ลัด: Alt+T เทรนด์, Alt+R ray, Alt+H แนวนอน, Alt+V แนวตั้ง, Alt+B กล่อง, Alt+F Fib,
  Ctrl+Z ย้อนการวาด, Delete ลบเส้นที่เลือก, Esc ยกเลิก
- เวลาแสดงเป็นเวลาไทย (UTC+7) ไม่ว่าโบรกจะใช้เวลา server แบบไหน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `start-bridge.bat` | ดับเบิลคลิกเพื่อเปิด bridge |
| `bridge/bridge.py` | อ่านแท่งเทียนและ tick จาก MT5 แล้วส่งให้หน้าเว็บ (HTTP + Server-Sent Events) |
| `index.html` | โครงหน้า และ dialog ตั้งค่า |
| `app.js` | กราฟ, layout, ซิงก์ crosshair (ค่าที่แก้ได้อยู่บนสุดของไฟล์) |
| `mt5.js` | ดึงข้อมูลจาก bridge |
| `indicators.js` | สูตร indicator ทั้งหมด และรายการที่หน้า ƒx Indicators ใช้ |
| `drawings.js` | เครื่องมือวาดเส้น (เก็บใน localStorage ของเบราว์เซอร์) |
| `overlays.js` | แถบ session และ Volume Profile |
| `style.css` | หน้าตา |

ยังไม่มีการส่งคำสั่งซื้อขาย จะต่อยอดผ่าน bridge ตัวเดียวกันภายหลัง
